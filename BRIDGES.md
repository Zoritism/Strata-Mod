# Мосты к Strata

Автор внешнего runtime и расширений: Zoritism.

Поддерживаемая основа: **Strata v0.2.13**, commit `d2f096475817d4666c364c820b0ca830f751cfc5` в [официальном репозитории](https://github.com/Niko1221/Strata).

## Граница ответственности

В upstream остаются короткие вызовы внешнего кода. Настройки путей, правила чата и дополнения интерфейса реализуются в `runtime/core` и пакетах `folder-paths`, `chat-rules`, `strata-ui`. Полная копия исходников или готового приложения Strata здесь не хранится.

| Точка подключения | Что передаётся внешнему коду |
| --- | --- |
| Сервер и хранилище | Настроенные пути, маршруты расширений, рабочая папка текущего чата. |
| Контекст чата | Сохранённые инструкции только для текущего диалога. |
| Интерфейс чата | Загрузка внешнего интерфейса, редактирование, повтор ответа и сведения о происхождении веток. |
| Загрузчик приложения | Выбор настроенной среды и подключение внешнего runtime. |

Пути разрешаются из настроек выбранной установки. Инструкции одного чата не добавляются в запрос другого чата. Интерфейс загружает только включённые пакеты из локального реестра.

## Проверка перед записью

`scripts/bridge.mjs` поддерживает готовую сборку и дерево исходников:

```sh
node scripts/bridge.mjs "<каталог приложения>" --plan
node scripts/bridge.mjs "<корень исходников Strata>" --source --check
```

Оба флага возвращают JSON без изменения проверяемых файлов. В нём указаны версия upstream, commit, входные файлы `inputs` и предполагаемые записи `writes` с SHA-256 до и после изменения. `before: null` означает новый файл.

При повторной установке сверяется весь предыдущий `strata-bridge-receipt.json`, включая файлы, которые не требуют новой правки. Неизвестная версия, изменённые точки подключения, неполный мост или посторонняя правка приводят к отказу. Повторное применение уже установленного комплекта не меняет его байты.

`scripts/overlay-install.mjs` использует этот план для подготовки и проверки установки. Применять `bridge.mjs` вручную к рабочей программе обычно не требуется: установщик также обрабатывает runtime, пакеты, резервную копию и откат.

## Исходный патч

`bridges/upstream-v0.2.13.patch` показывает изменения для проверенного исходного дерева. Это обзорный патч, а не замена установщика готовой программы. При переносе на следующий upstream нужно заново сверить API и поведение, обновить точные точки подключения, проверить исходный и собранный варианты, затем выполнить тесты совместимости.

Помимо проверки контрольных сумм, проверяются запуск host, доступность модулей интерфейса по HTTP, сохранение пользовательских данных и изоляция правил разных чатов.
