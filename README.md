# Strata-Mod

Автор: **Zoritism**. Общие расширения для Strata на Windows.

Три расширения и внешний runtime устанавливаются поверх **Strata 0.2.13** через небольшие мосты. Сначала установите Strata из [официального проекта](https://github.com/Niko1221/Strata), затем добавьте этот комплект.

## Что входит

| Расширение | Назначение |
| --- | --- |
| Папки и пути | Настройки размещения данных, проверка путей и управляемый перенос. |
| Правила чата | Постоянные пользовательские инструкции отдельно для каждого диалога. |
| Интерфейс Strata | Показатели компьютера, адаптация узкого экрана, сворачивание файлов и управление доступом по локальной сети. |

## Установка поверх Strata

Нужна установленная **Strata 0.2.13 для Windows x64**. Установщик использует Node из её каталога и уже имеющийся компилятор .NET Framework Windows. Он не скачивает зависимости. Если нужного компонента нет, установка завершается сообщением об этом.

1. Закройте выбранную Strata и её работающий host.
2. Скачайте или клонируйте этот репозиторий в отдельную папку.
3. В командной строке из папки репозитория сначала проверьте план, подставив реальный путь вместо заполнителя:

```bat
install.cmd "<папка установленной Strata>" --dry-run
```

4. Выполните установку:

```bat
install.cmd "<папка установленной Strata>"
```

После установки запускайте **Strata Extensions.exe** в папке выбранной Strata. Поддерживаются каталоги с `host` и `node` рядом с приложением и структура, где эти файлы находятся в подкаталоге `app`.

Установщик проверяет версию, точки подключения, контрольные суммы уже установленных мостов и состояние программы. Затем готовит файлы отдельно, сохраняет заменяемые версии в `extensions/backups` и записывает проверенный комплект. Неизвестные изменения не перезаписываются автоматически. При ошибке записи выполняется откат записанных файлов; если откат невозможен, выводится путь к резервной копии и отчёту.

### Настройки и данные

По умолчанию сохраняются **существующий нативный профиль Strata, история, настройки, рабочие папки и пути моделей**. Установка не создаёт отдельную копию переписок и не переносит веса моделей.

Собственные данные расширений по умолчанию находятся в `extension-data` рядом с установленной Strata. При первой установке можно выбрать другой каталог:

```bat
install.cmd "<папка установленной Strata>" --data-root "<каталог данных расширений>"
```

Этот параметр задаёт место собственных данных расширений; он не перемещает нативный профиль. Если `storage.json` уже существует, его параметры сохраняются. Дальнейшие изменения выполняются через «Папки и пути». Перенос применяется отдельно с проверкой сохранности файлов.

### Обновление и откат

Перед обновлением снова закройте Strata. Поддерживается только явно проверенная версия upstream; установка поверх иной версии останавливается. После обновления самой Strata дождитесь совместимых мостов и примените комплект расширений повторно.

Для возврата файлов из конкретной резервной копии:

```bat
install.cmd "<папка установленной Strata>" --rollback "<папка резервной копии>" --dry-run
install.cmd "<папка установленной Strata>" --rollback "<папка резервной копии>"
```

Откат проверяет сохранённые контрольные суммы и не заменяет файлы, изменённые после установки. Рабочие пользовательские данные не откатываются вместе с кодом. Сохраняйте резервную копию до проверки обновления.

## Доступ с телефона

«Удалённый доступ» предназначен для локальной сети. Требуется отдельная подготовка сертификата, адреса и учётных данных; установка расширений сама не открывает сеть и не создаёт доступ извне. Подробности — в [инструкции LAN](scripts/lan-ui/README.md). Сертификаты, пароли и список устройств остаются локальными.

## Проверки и разработка

В 0.1.1 исправлено продолжение оборванного ответа: runtime проверяет свободный контекст, при необходимости вызывает штатное сокращение и допускает повтор только после успешной проверки. Незавершённые вызовы инструментов не исполняются повторно из обрывков. Подсказка о дописывании файла применяется только к файловым операциям. Лимит повторов остаётся конечным.

Исходники находятся в `runtime/core`, тематические пакеты — в `extensions`. Принцип мостов и границы изменений описаны в [BRIDGES.md](BRIDGES.md).

При наличии Node 24.12 или новее тесты запускаются без установки npm-пакетов:

```sh
node --test tests/*.test.mjs
```

Можно использовать тот же Node из установленной Strata, указав полный путь к его исполняемому файлу. Проверки используют синтетические данные; проверки Windows выполняются только там, где доступны соответствующие штатные средства.

Для необязательной проверки мостов можно явно указать **чистую** распакованную Strata 0.2.13 и исходники фиксированного commit из `BRIDGES.md`:

```powershell
$env:STRATA_TEST_CLEAN_RELEASE = "<каталог чистой Strata 0.2.13>"
$env:STRATA_TEST_UPSTREAM_SOURCE = "<корень чистых исходников Strata>"
node --test tests/*.test.mjs
```

Без этих материалов соответствующие проверки пропускаются; синтетические тесты продолжают работать. Тесты ничего не скачивают и не изменяют оригиналы. Временные материалы находятся в `.work`.
