# Доступ к Strata по локальной сети

Автор: Zoritism.

Скрипты устанавливаются в `tools/lan-ui` внутри выбранной Strata Extensions. Они читают `appDir` из `installation.json`: `.` означает штатный `node/node.exe` рядом с приложением, `app` — прежний `app/node/node.exe`. У старых установок без этого поля сохраняется расположение `app`. Данные доступа остаются в `data/lan-ui`; используются стандартные средства Windows.

Подготовку сертификата и первого пароля выполняют отдельно через `prepare.ps1` в PowerShell 7, передав каталог данных, частный IPv4-адрес, размер подсети и при необходимости порты. Скрипт создаёт новые локальные секреты; готовые `access.txt`, `server.pfx`, конфигурацию и список устройств нельзя включать в репозиторий. На телефон переносится только публичный CA-сертификат.

`Launch.cmd` открывает окно запуска Strata и шлюза. `control.ps1` управляет только своим шлюзом, `startup.ps1` — своим ярлыком входа в Windows. Порт приложения берётся из `config.json`; правило `firewall.ps1` ограничено настроенными адресом, подсетью, портом и исполняемым файлом Node. Для изменения правила Windows требуется подтверждение повышения прав. `firewall.ps1 -ValidateOnly` проверяет конфигурацию без изменения Windows.

`launch.ps1 -ValidateOnly` проверяет путь запуска Strata и ничего не запускает. Автозапуск Windows открывает Strata и шлюз; модели автоматически не загружаются. Скрипты не скачивают дополнительные программы.
