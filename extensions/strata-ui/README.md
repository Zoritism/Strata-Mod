# Интерфейс Strata

Автор: Zoritism.

Общие дополнения оболочки: показатели компьютера в верхней панели, блок «Удалённый доступ» возле выбора модели, мобильная компоновка и раскрываемый блок файлов сообщения.

Показатели состоят из названия, числа и шкалы заполнения. Высокая загрузка CPU/GPU означает работу устройства; заполнение RAM/VRAM показывает занятую долю памяти. Недоступный счётчик показан как «—». Сбор идёт на компьютере Strata только при открытой видимой панели; один общий серверный снимок используется всеми зрителями в течение трёх секунд. Телеметрия не записывается на диск.

Настройка видимости хранится в штатной папке данных `strata-ui/settings.json`. Удалённый доступ использует прежние настройки, сертификаты и разрешённые устройства; перенос расширения не переписывает их. Управление устройствами доступно только с компьютера. Уже настроенный сетевой шлюз сохраняет свой жизненный цикл при отключении интерфейсного расширения; выключение сети выполняется явной кнопкой в блоке доступа.

GPU-показатели используют доступный `nvidia-smi`; отсутствие драйвера показывается как отсутствие данных. Дополнительные программы автоматически не устанавливаются. Windows-команды LAN требуют установленных скриптов `tools/lan-ui`; настройки и сертификаты создаются отдельно на каждом компьютере.

Интерфейс использует палитру Strata. QR-модуль сохраняет исходную лицензию MIT и авторство Kazuhiko Arase.
