# Правила чата

Автор: Zoritism. API 1. Текущая версия указана в extension.json.

Кнопка «Правила» находится рядом с «Субагенты» в панели чата. Она открывает редактор постоянных пользовательских инструкций для текущего диалога. Пустое поле удаляет правила этого чата.

Правила сохраняются в папке конкретного чата: `extensions/chat-rules/rules.json`. На старом host без `chatData` используется совместимый путь `extensionData/chat-rules/chats/<chat-id>.json`. Перед каждым новым запросом ядро читает правила выбранного чата и передаёт их отдельным системным блоком в обычный запрос и Harness. История уже отправленных сообщений не переписывается. Системные инструкции приложения и явная просьба пользователя в текущем запросе остаются главнее.

Нет сторонних зависимостей. В пользовательских правилах следует задавать желаемый стиль и поведение; длина ограничена 12 000 символами.

Расширение требует мост чтения правил в ядре Strata Extensions. Другие тематические расширения для его работы не нужны.
